# IRONCORE FITNESS — Gym Website Demo

A premium, responsive gym website and admin dashboard built with Next.js, TypeScript, Tailwind CSS, Framer Motion and Lucide icons.

## Routes
- `/` — Public gym website
- `/admin` — Admin dashboard UI preview

## Getting started
```bash
npm install
npm run dev
```

## Demo content notice
- IRONCORE FITNESS is a fictional demo brand.
- Trainer names, membership prices, operating hours, member records and analytics are illustrative sample content.
- The enquiry form is frontend-only. It does not send or store submissions.
- The admin dashboard is a visual prototype with sample data. It does not have authentication, a database or live member management.
- Replace all sample content with verified gym information before using this as a client website.

## Deployment
Import this repository into Vercel. Use the Next.js framework preset and the default build command.
